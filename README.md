# Voice Agent Pad

一个极简 Windows 悬浮语音输入器，用来把语音快速变成文字，并粘贴到当前正在使用的 Agent、ChatGPT、Codex、Obsidian 或任意输入框里。

## 2026-09-05 可转发内测版

`交付包/VoiceAgentPad-0.2.0-beta.5-lite-win-x64.zip` 为默认轻量免安装 Windows x64 包，内置本地 Paraformer、Python、悬浮球、快捷键、通用兼容实时写入、兼容输入降级、历史记录和词包入口。Qwen 本地整理/翻译已改为软件内可选扩展安装：`交付包/VoiceAgentPad-0.2.0-beta.5-ai-extension-win-x64.zip`，支持填写国内源链接或选择本地 ZIP。旧版 `0.2.0-beta.1` 为完整包，约 2.19 GB。详见 `交付包/0.2.0-beta.5-轻量版说明.md`。不含个人资料、旧实验引擎或 Torch；未签名，不承诺所有系统和输入框兼容。开发版继续使用原配置，便携版使用 `%APPDATA%\VoiceAgentPad` 独立资料目录。

构建入口：`npm run release:licenses`、`npm run build:portable:lite`、`npm run build:portable:full`、`npm run build:ai-extension`。脚本从已安装运行环境筛选依赖、验证模型并生成逐文件清单，默认拒绝覆盖已有发行目录。`npm run release:manifest` 仅用于首次发布前重新生成清单，已分发的 ZIP 不应静默覆盖。

## 2026-09-05 实时外部输入与底部声纹

常规设置新增「实时写入当前输入框」，默认开启。本地 Paraformer 普通识别时，先点目标聊天框，再用录音快捷键说话，已稳定的文字会持续追加到目标框，同时保留软件内的实时预览。停止后只补尾部，不重复输入整段，也不自动发送消息。

最小化后隐藏悬浮球和主窗口，录音时在屏幕底部居中显示不抢焦点的声纹与计时；完成后自动收起。原有显示/隐藏快捷键和托盘可以恢复主窗口。中文转英文仍然停止后翻译并确认，不实时发送中文。适用范围、保护规则及验收结果见 [实时输入与声纹说明](docs/2026-09-05-live-input-hud.md)。

## 2026-09-05 六项新功能

- 本地文字整理：原文 / 日常 / 条理三种模式。录音时实时显示原文，停止后只整理本次新增文字，不重复识别整段音频。日常与条理默认预览确认。
- 原文对照：显示删改位置，可恢复本次原文；不会自动撤销已输入到外部软件的内容。
- 个人词典与“记住改词”后续已按用户要求移除。
- 中文文字规范化：完整 OpenCC 简体转换；可关闭的数字单位处理和基础句末标点。完整断句由本地文字模型辅助。
- 草稿与输入保护：增量保存草稿，正常退出前再次保存，重启恢复；清除后不恢复。取消录音或整理不自动输入，过期结果不能覆盖新文字。
- 历史搜索、原文查询、置顶和单条删除；可选保留期限，默认不自动过期。
- 剪贴板保护：直接输入不使用剪贴板；粘贴临时使用后恢复常见格式。如果期间用户复制了别的内容，不覆盖。遇到不支持的原生格式则改走直接输入。
- 系统托盘、快速/节能待命、手动释放模型。快速待命保留流式 ASR；节能待命按空闲时限释放识别模型。文字模型在空闲后释放。

本地整理使用 `llama.cpp b10816 + Qwen3 1.7B Q8_0`，CPU 四线程，不需云端 API。文字模型约 1.83 GB，连同运行程序和下载压缩包约 1.90 GB；这是新增模块大小，不是整个旧项目大小。模型不会随启动自动联网下载。

完整流程、已知边界、验收命令见 [新功能使用与验证](docs/2026-09-05-product-features.md)。旧快捷键和麦克风配置保留。当前正在运行的旧版必须正常退出并重新打开，才会加载新版代码。

## 本地识别

默认使用 `sherpa-onnx + Paraformer streaming INT8`，模型文件约 226 MiB，CPU 两线程，不需要 API Key。下载完成后，识别期间完全离线。SenseVoice 和 Whisper 可手动切换。

只安装流式引擎所需的轻量依赖和模型：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-streaming.txt
.\.venv\Scripts\python.exe scripts\setup_streaming.py
```

`setup_streaming.py` 下载官方文档推荐的模型文件并校验 SHA-256。识别脚本只读取本地文件，没有网络请求，也不需要 Torch 或显卡。项目中之前安装的其他引擎及模型仍保留，所以整个旧项目占用会大于新模型本身。

安装包括 SenseVoice、Whisper 的全部可选本地引擎：

在项目目录运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-local.txt
```

如果安装 Torch 时网络不稳或出现哈希不匹配，可以先单独安装 CPU 版 Torch：

```powershell
.\.venv\Scripts\python.exe -m pip install --no-cache-dir torch torchaudio --index-url https://download.pytorch.org/whl/cpu
.\.venv\Scripts\python.exe -m pip install --no-cache-dir funasr modelscope soundfile
```

然后在设置里选择：

- 转写模式：`本地识别`
- 语言：`中文`、`英文` 或 `中英文`
- 本地引擎：`Paraformer 流式（推荐）`
- 录音触发方式：`点按切换` 或 `按住说话`
- 麦克风输入：选择 `系统默认麦克风`，或指定耳机/电脑内置麦克风
- Python：`D:\GPT 工作区\voice-agent-pad\.venv\Scripts\python.exe`
- SenseVoice 模型：`iic/SenseVoiceSmall`
- Whisper 模型：默认先用 `base`
- 设备：默认先用 `CPU`

应用启动时预热 Paraformer，此后复用同一个识别进程。AudioWorklet 每 50 毫秒传递一次原始音频，sherpa-onnx 内置重采样，模型在具备上下文后增量解码。结果会以几个字或词为一批更新，未完成片段可以被模型修正，不承诺每说一个字就立即出现。

停止后只补齐尾部解码，不整段重识别。每次录音具有独立编号，过期结果不会写入下一次录音。流式模式不累计整段音频文件，持续保留的是文字；处理积压超过 8 秒会明确报错并保留已识别文字。

SenseVoice/Whisper 使用原有分段转写路径。模型大小不直接等于你的场景下的准确率；需要以实际口播测试判断。中文模式做简体转换与中文输出过滤，英文模式保留英文，中英文模式保留两者。Paraformer 本身是双语模型，这里的语言选择是输出过滤，不是专门训练的单语拒识器。

## 本地流式验收记录（2026-09-05）

- 机器：Ryzen AI 9 H 365，32GB 内存；CPU 两线程。
- 公开 10.05 秒音频按实时速度回放：约 1.28 秒首次出字，停止前更新 12 次，尾音解码约 49 毫秒。
- Electron 实际录音链路（公开音频模拟麦克风）：约 1.38 秒首次出字，停止到定稿约 0.19 秒。
- 已验证：连续录音追加、手动文字保留、静音不出字、8/16/48kHz 音频、设置保存、关闭面板保留悬浮球、启动期间松开快捷键、Windows 自动输入到独立测试文本框。
- 以上是最初接入流式识别时的测试结果，不是个人语音准确率测量。当时没有标点模型、热词解码或 AI 整理；当天后续已加入本地文字整理与替换词典，见上方新功能。

```powershell
npm run check
.\.venv\Scripts\python.exe scripts\probe_streaming.py --realtime --output tmp\streaming-probe.json
npm run test:streaming-client
npm run test:streaming-ui
```

界面测试需要可用的 Playwright（本机使用 Codex 配套运行库的 `NODE_PATH`），会启动独立窗口和数据目录，以公开 WAV 模拟麦克风。不会采集用户真实麦克风或写入已有聊天框。

模型来源：[sherpa-onnx 官方流式 Paraformer 文档](https://k2-fsa.github.io/sherpa/onnx/pretrained_models/online-paraformer/paraformer-models.html)。模型与运行库采用 Apache-2.0 许可，下载记录在 `models/paraformer-streaming-zh-en/download-manifest.json`。

## 云端 OpenAI 转写

1. 打开设置。
2. 选择 `云端 OpenAI`。
3. 填入 OpenAI API Key，或提前设置系统环境变量 `OPENAI_API_KEY`。
4. 模型默认是 `gpt-4o-mini-transcribe`，也可以改成 `gpt-4o-transcribe`。

云端模式需要网络和 API Key，实际准确性与延迟需要用相同音频比较。本地文字整理不会在失败时静默切到云端。

## 使用流程

### 快捷键直输

点按切换：

1. 把光标放在你想输入的地方，比如 Codex 输入框。
2. 按开始/停止快捷键，默认是 `F8`。
3. 说完后再次按同一个快捷键。
4. 等待识别完成，文字会自动粘贴到刚才的输入框。

按住说话：

1. 在设置里把 `录音触发方式` 改成 `按住说话`。
2. 把光标放在目标聊天框里。
3. 按住开始/停止快捷键开始说话。
4. 松开快捷键后自动停止录音，识别完成后会粘贴回目标聊天框。

### 悬浮球预览

点按切换：

1. 点击悬浮圆钮开始说话。
2. 说话时输入框会逐步追加文字。
3. 再次点击悬浮圆钮停止，等待最后一小段收尾。
4. 不想保留当前文字时，点输入框下方的 `清除`。
5. 点击文字框即可编辑；按 `Enter`，把文本粘贴到当前输入框。

按住说话：

1. 在设置里把 `录音触发方式` 改成 `按住说话`。
2. 按住悬浮圆钮开始说话。
3. 松开后自动停止录音并转写。
4. 点击文字框即可编辑；按 `Enter`，把文本粘贴到当前输入框。
