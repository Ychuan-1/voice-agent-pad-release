以上来源存在不等于可直接导入；英文混说、多音字、缩写发音及同名歧义均需适配。不能将下载的输入法二进制词库当成本软件的模型文件。

## 需要自行整理的补充包

- AI 工具与模型：用户常用的产品名、模型名、缩写与确认过的别称。优先覆盖当前实际使用的术语；THUOCL IT 老词表不能替代这个包。
- 生图与视频制作：从实际工作流整理软件名、节点名和常用概念，保存逐条来源与发音，不整段复制产品文档。
- 音乐制作与音频：另行整理采样率、混音、音轨、效果器等术语；音乐作品名称数据不能替代制作术语。

这三类是自建计划，尚无本轮完成的词包，不计入“已找到可适配的专业词表”数量。建议先完成 AI 与软件，再按使用需求扩展其他包。

## 可选下载体验（待实现）

入口建议：设置 -> 词典 -> 专业词包，与个人词条分开展示。

1. 未下载时只显示目录元数据，不预装全部词库。
2. 每项显示用途、词条数、上游日期、包版本、下载大小、安装大小、来源、许可和状态。未知信息显示待核实，不填估计值冒充实测值。
3. 提供下载/取消、启用开关、更新和删除；下载成功不等于已启用，用户确认后才参与纠正。
4. 支持查看样例、冲突和最近命中记录；命中计数只在本机保存，不收集或上传原始录音。
5. 公共词包与个人词条独立存储，更新、卸载公共包不能覆盖个人修改。个人明确规则优先；公共包之间有歧义时提示选择。
6. 不默认自动更新。更新先验证，再原子替换；失败保留旧版，卸载只移除该包的数据。
7. 下载需要联网；下载后的识别和词典匹配本地运行，不依赖付费接口。先以各包实际测量的体积展示，不能用原始文本大小代替完整运行成本。

## 接入与安全边界

当前代码的 Paraformer 使用本地流式识别，现有词典是转写后的精确替换。已安装的 sherpa-onnx `from_paraformer` 提供同音纠正配置，但项目尚未接入。后续优先验证该能力，不为词包直接替换现有语音模型。[上游接口](https://github.com/k2-fsa/sherpa-onnx/blob/master/sherpa-onnx/python/sherpa_onnx/online_recognizer.py)

真正的解码热词加权与后处理不同；不能把 Paraformer 同音纠正宣传成已经支持 Transducer 热词加权。[官方热词说明](https://k2-fsa.github.io/sherpa/onnx/hotwords/index.html)

- 上游下载 URL 必须固定版本；目录记录来源修订、适配器版本、SHA-256、许可、大小限制、语言与适配能力。GitHub 的 blob SHA 不是可替代下载校验的 SHA-256。
- 客户端只读取受控数据格式，不执行词库中的脚本、Lua、安装命令或 YAML 自定义对象；下载解压须防止路径越界、符号链接与超大展开内容。
- 初期只自动应用明确确认的错词映射。同音候选不盲目强替换，不能把发音相同当成语义相同。
- 大词库用于候选检索，不能逐条全表扫描每次流式结果，也不把全集塞进整理模型上下文。仅对稳定片段处理，避免文字来回跳。
- 不默认读取 Obsidian、聊天记录、联系人或屏幕来生成个人包；未来导入须由用户选择文件并预览。

## 上线前验证

每个包分别记录：专业词识别前后表现、被纠正的数量、正常句子被误改的数量、首字和结束延迟、增量内存、磁盘占用。先做小范围试用，不承诺下载后必然提高整体准确率。

测试须覆盖：不启用包时行为不变；启停与卸载即时有效；重启保持选择；个人规则不丢失；同音歧义和中英文混说；重复包去重；断网/取消/损坏包/版本回退。金额、人名、否定语气不得因为专业词包而被静默改写。

后续实施顺序：精选 AI/软件词包与导入预览 -> 专业词包管理与可选下载 -> 中文同音纠正实验 -> 英文发音及更多领域。所有阶段保留原文恢复。
