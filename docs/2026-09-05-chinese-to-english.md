# 中文转英文与个人词典移除

## 入口与流程

设置 -> 常规 -> 语言 -> 中文 → 英文 -> 保存。

仍使用原来的点按 / 按住说话快捷键和麦克风。录音中显示中文转写，停止后将本次新文字交给本地 Qwen3 1.7B 翻译，不重新识别整段音频。英文完成后显示在原输入框，原文对照中保留中文，可恢复原文、编辑、复制或确认后输入到目标聊天框。

该模式优先于原文 / 日常 / 条理，主界面改为「英文译文」状态；切回其他语言后恢复原有表达模式，不修改用户原先选择。手动编辑中文后，星光按钮是「翻译当前文字」。语言选择必须点保存后生效，识别框下方同步显示「中文 → 英文」。历史记录保留中文原文、英文结果与翻译模式。

第一版在录音过程中显示中文，不是边说边出英文；英文在停止后生成。译文始终先预览，即使关闭普通整理预览也不会直接送进目标输入框。按 Enter / 输入按钮确认后才输入，不发送聊天消息。已输入内容不会在再次点击时重复插入。

例：

> 你明天下午有空吗？我们一起去喝咖啡吧。

本机测试输出：

> Will you be free in the afternoon tomorrow? Let's go have coffee together.

## 本地和异常保护

复用已有 `llama.cpp + Qwen3 1.7B Q8_0`，不新增模型下载或付费 API。本地识别 + 本地翻译不会上传录音或文字；如果用户自己选择云端识别，音频仍按原云端设置处理，但翻译步骤依然本地运行。

中文为主的语音使用现有中英识别通道，以保留夹带的 ComfyUI 等英文名称；传给识别引擎的是已有 `zh-en` 参数，不把界面上的 `zh-to-en` 当成模型语言编码。

翻译模型接收结构化的待译文本，把其中的问题、指令也当作待译内容，不回答或执行它们。保留数字、时间、否定和不确定语气是提示要求；规则另检查数字和部分限制表达，但不等同于语义质量保证。小模型仍可能错译、漏译或缩窄含义，因此保留强制确认和原文。

英文结果缺失、输出仍包含中日韩文字、模型不可用或请求失败时，保留原文并显示翻译未完成。超出 1000 字时要求分段，避免小上下文截断；取消后迟到结果不能覆盖草稿。

本机五条短句测试翻译约 1 至 3.6 秒，首次通过完整界面处理约 5.2 秒，包括加载；实际随句长、机器负载、模型冷启动变化，不能视为固定速度保证。

## 移除个人词典

已移除设置里的「词典」页、增删改规则入口、编辑后「记住这个改词」提示及其事件处理。

旧设置文件的 `dictionary` 字段在加载时丢弃，不再执行；下一次保存设置时不再写入。即使旧客户端传入此字段，也不会恢复个人替换。未删除语音历史、草稿、麦克风或快捷键配置。

日常 / 专业可选词包保留。专业词包中明确的公共别名规则仍由词包开关控制；本次移除的是个人编辑和自动记词功能，不是所有公共词包。

## 验证

- 九项基础测试：旧个人字段忽略、普通文本不再按个人规则替换、保留词包显式规则，以及简体、数字、原文对照和跨语言提醒。
- 十二项词包测试：原有十六个词包仍可按需安装、启停和离线使用，旧个人数据不参与词包匹配。
- 本地模型实测：五条原整理用例与五条中文译英文用例，包括问句、否定、时间金额、英文软件名以及指令形式的待译内容。
- 专门的 Electron 测试覆盖语言选项保存 / 重启、译文与原文恢复、历史记录、错误语言回退、模型失败、取消、长文本保护，以及退出翻译模式恢复原设置。
