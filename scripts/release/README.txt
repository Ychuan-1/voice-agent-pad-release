Voice Agent Pad 0.2.0-beta.6 | Windows x64 本地语音输入助手

这是可转发的免安装内测版，不是已签名的正式商店软件。

一、开始使用
1. 先完整解压 ZIP 到一个固定目录，例如 D:\VoiceAgentPad。不要在压缩软件里直接运行。
2. 双击 VoiceAgentPad.exe。不要只把这个 exe 单独拷出去，旁边的文件都是运行依赖。
3. 点击齿轮，选择麦克风和语言，按需要修改录音方式，点击保存。
4. 默认 F8 为点按开始/停止。先点击目标聊天框，再按 F8 说话，再按 F8 结束。
5. 如改为“按住说话”，则按住 F8 说话，松开结束。不自动按 Enter 发送消息。
6. 默认 Ctrl+Alt+H 隐藏/显示窗口，Ctrl+Alt+Enter 输入当前待输入文字。
7. 可选双击 Create Desktop Shortcut.cmd 创建快捷方式；仅写入当前用户桌面，不要求管理员。

二、轻量包已经包含
- 本地 Paraformer 中英流式识别、简体中文、可选麦克风、实时声纹。
- 浮球拖动、点击框内编辑、复制、清除、追加输入、三种可设置快捷键。
- 目标聊天框实时追加：常规里的“实时写入当前输入框”默认开启，默认使用通用兼容模式。
- 通用兼容模式不要求目标框是标准 Windows 文本框，适配更多聊天软件和网页输入框。
- 兼容输入降级：目标窗口权限隔离或输入被拦截时，会在结束后尝试最终输入。
- 最小化后隐藏浮球和窗口，录音时仅在屏幕底部居中显示声纹和计时。
- 本地草稿恢复、历史搜索/置顶/删除、节能待命、开机自启动开关。
- 日常与专业可选词包目录，按需联网下载。没有个人词典功能。
- 内置 Python、Electron 和识别模型，不需要单独安装 Python、Node 或 Ollama。

三、AI 整理扩展
- 轻量包默认不内置 Qwen 本地整理模型，因此日常整理、条理整理、中文转英文默认是可选扩展。
- 进入 设置 -> 文字，直接点击 AI 整理扩展卡片里的“下载 AI 扩展”，像下载词包一样下载安装。
- 已经拿到 AI 扩展 ZIP 时，也可以点“选择本地 ZIP”安装。
- 如需要换成自己的下载源，可展开“高级：手动下载源”填写链接。
- 安装扩展后重启软件，设置 -> 文字 显示 Qwen3 1.7B 本地 CPU 即表示生效。
- AI 扩展不需要云端 API，但需要额外磁盘、内存和 CPU。

四、国内源建议
- 长期公网分发建议使用阿里云 OSS、腾讯云 COS、七牛 Kodo 等国内对象存储。
- 如果只是两台电脑在同一 Wi-Fi 下传扩展包，可运行交付包里的 启动AI扩展局域网下载.ps1，复制脚本显示的 http 地址到另一台电脑的软件中下载。
- GitHub Release 可作为国外备用源，但不建议作为国内用户的唯一下载源。

五、重要区别
- 实时写入只追加稳定原文，停止后不重复整段输入。此模式不对已写入外部的文字再次 AI 改写。
- 想要“日常/条理”整理后再输入：关闭实时写入，再使用预览确认流程。
- 中文转英文：录音时显示原文，停止后本地翻译，确认后再输入，不是实时同声传译。
- 不支持的目标框、密码框、只读框、选中已有文字、移动光标或手动输入，会阻止或暂停外部实时输入。请回软件复制并核对需要的部分。
- SenseVoice/Whisper 旧实验引擎不在这个包里，相关选项不可选。核心包不包含 Torch。
- 云端模式需要用户自己提供 API Key，可能产生供应商费用；默认不启用，不静默切换云端。

六、运行条件
目标平台为 Windows 10/11 x64，建议 8 GB 内存起步；运行 AI 整理建议 16 GB。解压轻量包前请留至少 2 GB 空间，安装 AI 扩展前请额外留至少 3 GB 空间。
通用兼容模式会向当前前台窗口发送文字；开始录音前请先点中正确聊天输入框。管理员权限窗口、安全输入框、部分游戏和被企业策略限制的窗口仍可能被 Windows 拦截。
使用系统 Windows PowerShell 和 .NET 的输入辅助功能。企业限制、系统权限差异、输入框兼容性可能阻止自动输入。不要为此关闭杀毒软件或绕过组织安全策略；可以先使用软件内录音和复制。
如果麦克风无声，检查 Windows 隐私设置中的桌面应用麦克风权限，再到软件中选择正确输入源。
如果出现 SmartScreen 或安全提示：本内测版没有购买代码签名证书，请先核实来源和校验值；有疑虑不要运行。不承诺所有电脑都不会弹安全提示。

七、数据与转发
个人设置、草稿、历史、词包及缓存保存在 %APPDATA%\VoiceAgentPad，不放在解压目录。
本发行包没有包含制作者的设置、历史、录音、密钥或下载过的私人词包状态。
请转发原始 ZIP，不要把自己的 AppData 目录打包发人。
默认本地录音识别不上传音频。AI 扩展安装后，本地整理和翻译也只在本机运行。下载词包、下载 AI 扩展、使用云端模式等明确联网功能除外。参阅 PRIVACY.txt。

八、退出、更新、卸载
最小化不是退出；用浮球关闭按钮或托盘“退出”结束程序。
更新时先正常退出，解压新版到新目录，直接运行。保留同一个 %APPDATA%\VoiceAgentPad 数据目录。
程序目录移动后会重新解析内置 Python，不依赖原电脑路径；桌面快捷方式需要重新创建。
卸载：正常退出后删除解压目录和对应快捷方式；如还要删除私人数据，再手动删除 %APPDATA%\VoiceAgentPad。不要在卸载前忘记导出需要的文字。
