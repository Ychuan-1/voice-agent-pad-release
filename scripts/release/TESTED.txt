Voice Agent Pad 0.2.0-beta.1 验证范围

已经完成的自动化检查：
- 源码语法与项目检查、文字规范化/草稿/历史/剪贴板回归、实时输入状态单元测试。
- 使用本发行包内的 exe、Python、Paraformer 与 Qwen 模型启动；清空开发环境 NODE_PATH、PYTHONHOME、PYTHONPATH，并限制 PATH 为系统目录。
- 使用隔离的空用户配置，确认未携带作者历史、草稿及云端密钥。
- 用模型仓库附带 WAV 模拟麦克风，经真实本地识别器完成录音，录音尚未结束时目标测试框已有文字。
- 普通窗口与最小化状态分别检查：主窗口显示策略、声纹、只补尾部、不重复、没有 Enter 自动发送。
- 中文转英文实际生成英文，确认前不输入，原文保留。
- 开发测试覆盖 textarea 与 contenteditable 富文本、焦点/光标变化、选区、密码和只读保护。

这些检查不等于已经在所有用户电脑、真实麦克风和所有聊天软件逐一验收。
应优先让少量试用者测试：Windows 安全提示、麦克风权限、F8 冲突、目标输入框兼容性、CPU 占用及冷启动等待。
本包未做代码签名，不能承诺不被 SmartScreen 或企业策略阻止。
新提出的六项差异化方向仍是设计稿，不属于上述测试或已完成功能。
