Voice Agent Pad | 产品介绍与当前范围

定位
面向 Windows 日常交流、学习笔记和给 Agent 下指令的本地语音输入工具。平时是一个悬浮球，需要时按键说话，文字进入当前输入框。

适合
- 希望主要依赖本机、不要按录音时长购买云端额度的人。
- 经常输入长句、分几次补充想法，希望减少打字的人。
- 需要软件内编辑、原文对照，而不是自动替自己发送消息的人。

不适合当作
- 保证逐字准确的专业听审工具。
- 实时同声传译、会议多人分离或全自动电脑 Agent。
- 所有第三方聊天框都无条件兼容的系统级输入法。

核心流程
普通听写：点击目标框 -> F8 -> 本地识别 -> 稳定文字实时追加 -> F8 收尾，不重复、不发送。
整理表达：安装 AI 扩展 -> 关闭实时写入 -> 录音 -> 日常/条理整理 -> 查看原文和结果 -> 确认输入。
中文转英文：安装 AI 扩展 -> 选择对应语言 -> 说中文 -> 停止 -> 本地翻译 -> 确认输入。
安静模式：最小化 -> 录音时仅显示底部声纹 -> 结束收起 -> 显示快捷键恢复窗口。

使用与费用
本包内的本地识别不要求购买云端 API。日常整理、条理整理和中文转英文需要安装可选 AI 扩展；扩展安装后也在本机运行，不要求云端 API。
云端识别是独立可选能力，必须由使用者自己配置，可能产生第三方费用。程序不自动替换到云端。

可转发简介
这是一个 Windows 本地语音输入助手内测版。解压后运行 VoiceAgentPad.exe，无需另外装 Python 或 Node。轻量包支持实时输入和底部声纹；安装 AI 扩展后支持本地整理和中文转英文。请先阅读 README.txt，再用不含隐私的短句试用；文字不会自动发送。遇到问题可按 FEEDBACK.txt 提供复现步骤。
